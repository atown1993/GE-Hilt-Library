# Savi's Workshop Gen2 (Oct 2026 chassis) — session 1, stock Gen1 blade

All 19 captures here are the Gen2 hilt driving an **original Gen1 stock segmented
blade** on the standard 8-channel tap rig. This wiring's channel map: CH3 DATA,
CH5 red gate, CH6 green gate, CH7 blue gate, segments base → tip CH2, CH1, CH0, CH4.
Decode with `tools/decode_dsl.py -c 3`. Findings: `CATALOG.md` §15.

This is the first of several sessions; the new addressable blade has not been
captured yet. `...-fromsleep-dup-...` is a byte-identical duplicate upload of the
`...-fromsleep-...` capture, kept as recorded.
